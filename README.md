# HR Analytics Dashboard – Power BI

An interactive HR Analytics Dashboard built using Power BI to analyze employee data and understand key HR metrics and workforce trends.

 Key Analysis

* Employee headcount and workforce overview
* Attrition rate and employee attrition analysis
* Department-wise and job-role-wise employee distribution
* Gender and age-group analysis
* Job satisfaction and employee-related insights
* Employee performance and workforce trends

 Tools & Skills

* Power BI
* Power Query – Data cleaning and transformation
* DAX – Measures and calculated metrics
* Data Modeling
* Interactive Dashboards & Data Visualization**

 Objective

The main objective of this project was to transform raw HR data into an interactive dashboard that helps identify workforce patterns, monitor attrition, and provide meaningful insights for better HR decision-making.

This project demonstrates my practical skills in data cleaning, data modeling, DAX, data visualization, and business-focused analysis using Power BI.
